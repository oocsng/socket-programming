# Socket Programming

Lab exercises and reference implementations for network socket programming in Python and C++.

## Structure

- `sample_code/`: Python client and server scripts demonstrating basic data transmission.
- `tcp_server_demo/`: TCP and UDP client and server implementations.
- `Ref/`: Reference projects, guides, and multi-threaded socket demos.

## Requirements

- Python 3.x
- C++ compiler (optional, for WinSock reference demos under `Ref/`)
